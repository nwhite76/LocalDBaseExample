LocalDB
A simple WinForms .NET 8 application demonstrating:
	- SQLite databases
	- Object-Oriented Programming
	- Classes and Objects
	- CRUD operations
	- GitHub source control

Requirements
	-Visual Studio 2022
	-.NET 8

Getting Started
	1. Clone the repository.
	2. Open the solution in Visual Studio.
	3. Restore NuGet packages.
	4. Run the application.

Features
	- Create a local SQLite database
	- Add students
	- Retrieve students
	- Store data in a project-based database file

Database Location
The SQLite database is stored in:
